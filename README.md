# Mikie Fisioterapia

Professional website for Mikie Fisioterapia - The first physiotherapy practice in Paraguay specialized in women's health, offering a unique trans AFAB perspective.

## 🌟 About

Mikie Fisioterapia provides specialized physiotherapy services for women in Asunción, Paraguay. As a trans AFAB physiotherapist, Mikie offers a unique perspective that combines professional training with lived experience of the female body, creating a completely safe and comfortable environment for women's healthcare.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn or pnpm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Ai-Whisperers/mikie-fisio.git
cd mikie-fisio
```

2. Install dependencies:
```bash
npm install
```

3. Copy environment variables:
```bash
cp .env.example .env.local
```

4. Run the development server:
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📝 Environment Variables
